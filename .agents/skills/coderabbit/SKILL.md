# CodeRabbit Code Reviewer

Automated code analysis and review standards:

## Review Checklist
- **Architecture**: Modularity, clean separation of concerns between API client, UI components, and state.
- **Safety & Robustness**: Null safety, graceful fallbacks for external APIs (e.g. RailRadar), error boundary handling.
- **Performance**: Minimizing re-renders in React, memoized calculations, responsive CSS.
- **Accessibility & UX**: High contrast, keyboard navigability, meaningful ARIA attributes.
