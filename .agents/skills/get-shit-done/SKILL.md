# Get Shit Done (GSD) Autonomous Execution Workflow

A spec-driven development and context-engineering workflow that enforces relentless execution until tasks are completely implemented, verified, and shipped.

## Core Tenets
1. **Zero Procrastination**: Always produce working code, never stop at placeholders or TODOs.
2. **Atomic Verification**: After modifying code, immediately verify with build (`npm run build`) and test (`pytest`) tools.
3. **Resilient Self-Healing**: When an error or barrier appears, diagnose root causes and solve directly without asking the user for trivial decisions.
4. **End-to-End Delivery**: Commit, push to remote VCS, and keep servers running.
